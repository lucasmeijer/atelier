Atelier is now on Pi 0.80.8

A three-release jump whose headline is not a model: it is a new ownership boundary. Authentication, availability, request assembly, and live catalogs now converge in Pi’s provider-scoped ModelRuntime.

Executive read

The architectural change

Pi stopped exposing storage and registry mechanics as the application contract.

01

One runtime

ModelRuntime replaces Atelier’s separate AuthStorage and ModelRegistry wiring.

02

Providers own auth

Each provider advertises and executes its API-key and OAuth behavior; Atelier supplies a neutral interaction surface.

03

Catalogs can move

Dynamic provider catalogs refresh and persist independently from Atelier’s favorites stored in models.json.

Directly relevant to Atelier

We embed Pi as an SDK, run our own browser OAuth UI, own credential persistence, resolve models for every agent session, and issue small background completions for workspace titles. Every one of those paths touched the removed APIs.

Mostly inherited, no UI work

Provider protocol fixes, pricing tiers, deferred tools, context metadata, session-affinity fixes, thinking-block fixes, and tab normalization arrive through the package update.

Auth focus

OAuth now belongs to the provider

Atelier remains the interaction host and credential owner, but no longer calls low-level OAuth adapters directly.

Before · 0.80.5Atelier enumerated built-in providers, called provider.auth.oauth.login(callbacks), cast the result, then wrote it through Pi’s exported AuthStorage.
→
Now · 0.80.8Atelier calls ModelRuntime.login(provider, "oauth", interaction). Pi performs provider discovery, login, persistence, refresh, and availability recalculation.
→
At request timeThe runtime resolves stored, ambient, and provider-specific auth; merges model headers; then dispatches. Atelier no longer assembles apiKey + headers + env.

Neutral browser protocol retained

Atelier maps Pi’s AuthInteraction into its existing dialog: auth_url, device_code, progress, and prompts for text, secret, selection, or manual redirect URL. The UI remains provider-neutral.

Credential safety retained

Atelier points ModelRuntime at its existing pi-config/auth.json. Pi’s own file-backed credential store now handles locking, persistence, and serialized OAuth token refresh; Atelier no longer reimplements that machinery.

New: xAI

Device-code OAuth is discoverable automatically. Grok 4.5 routes through Responses and supports low / medium / high thinking.

New: ambient flows

Provider-owned auth supports neutral info/link events and credential selection for Bedrock and Vertex.

New: dynamic gateways

Radius brings OAuth plus credential-specific model discovery and persistent dynamic catalogs.

Why this is better for Atelier

New OAuth providers no longer require a bespoke Atelier integration as long as they speak Pi’s interaction events. Provider-specific token refresh and request shaping stay in Pi, while Atelier keeps control of where credentials live and how browser users complete the flow.

0.80.6 → 0.80.8

Consolidated from Pi’s AI, agent-core, coding-agent, and TUI changelogs.

v0.80.8 high Atelier impact

16 July 2026
  • Breaking: provider-scoped Models.checkAuth/getAuth/login/logout; AuthInteraction replaces AuthLoginCallbacks; legacy OAuth registries and low-level built-ins removed.
  • Breaking SDK: CreateAgentSessionOptions.modelRuntime replaces authStorage + modelRegistry; those storage exports are removed.
  • Added: provider-owned auth and availability, credential enumeration, OAuth refresh, dynamic ModelsStore, Radius, xAI device OAuth, forced catalog refresh.
  • Request path: runtime owns model headers, auth resolution, and final header transforms.
  • Fixed: Codex session IDs clamped to 64 chars; lazy streams retain final messages; Cloudflare placeholders materialize after auth; thinking sections coalesce; tabs normalize; Bun binaries bundle OAuth.

v0.80.7 medium inherited impact

14 July 2026
  • Breaking: sendSessionIdHeader replaced by sessionAffinityFormat in custom model compatibility.
  • Added: cache-friendly deferred tool loading, OpenAI/Codex forced tool choice, Fable 5 xhigh/max.
  • Fixed: Bedrock API-key and ambient AWS auth, Cloudflare ambient IDs, OpenRouter affinity/context, Copilot Responses routing, Azure reasoning replay, Anthropic missing usage, OpenCode session headers, branch summaries under ambient auth.
  • CLI-only additions (message copy, paste fallback, Alt-symbol handling, npm uninstall fix) do not affect Atelier’s web UI.

v0.80.6 low migration impact

9 July 2026
  • Added opt-in max thinking across AI, agent core, SDK, RPC, and selectors.
  • Added input-token pricing tiers for accurate long-context costs.
  • Fixed compaction output budgeting, GPT-5.4/5.5/5.6 metadata and pricing, and empty signed Anthropic thinking blocks.
  • Added ~ expansion for shell paths (CLI setting; not used by Atelier).
