Typography

A deliberate type scale keeps operational interfaces consistent. Sans is for interface copy; mono is reserved for code, paths, and measured data. The reusable title style carries no surrounding space, so its composition controls the gap to adjacent content.

The owner sets data-progress-state to initial, in-progress, or finish, disables the button and sets aria-busy while it runs, and supplies a numeric --button-progress from 0–100. If finish content is omitted, replace the button instead of entering finish.

Popup menu

A compact elevated list for contextual actions and single-choice selection. It supports leading icons, secondary descriptions, trailing metadata, selection, disabled choices, separators, and semantic emphasis.

Composer model selection.popup-menu

This menu prefers to open upward like the composer, then flips horizontally or vertically whenever the preferred placement would cross a viewport edge.

Simple theme picker3 action items

For short, familiar choices, the popup can be nothing more than a list of Action Items.

.opens-above sets a preference, not a rigid position. Anchored menus automatically flip to remain visible. Use menuitemradio with aria-checked for a single-choice list.
