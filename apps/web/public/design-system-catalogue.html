Long-running interfaceinitial + in-progress required; finish optional
<button class="button primary progress-button"
  data-progress-state="initial"
  style="--button-progress: 0">
  <svg class="progress-button__perimeter" aria-hidden="true">
    <rect pathLength="100"/>
  </svg>

  <!-- Required states: arbitrary caption or content. -->
  <span class="progress-button__content" data-progress-content="initial">
    Download
  </span>
  <span class="progress-button__content" data-progress-content="in-progress">
    <i class="activity-spinner" aria-hidden="true"></i>
    Downloading…
  </span>

  <!-- Optional. Omit when replacing the button immediately at completion. -->
  <span class="progress-button__content" data-progress-content="finish">
    Downloaded
  </span>
</button>

The owner sets data-progress-state to initial, in-progress, or finish, disables the button and sets aria-busy while it runs, and supplies a numeric --button-progress from 0–100. If finish content is omitted, replace the button instead of entering finish.

Popup menu

A compact elevated list for contextual actions and single-choice selection. It supports leading icons, secondary descriptions, trailing metadata, selection, disabled choices, separators, and semantic emphasis.

Composer model selection.popup-menu
Favorites

This menu prefers to open upward like the composer, then flips horizontally or vertically whenever the preferred placement would cross a viewport edge.

Simple theme picker3 action items

For short, familiar choices, the popup can be nothing more than a list of Action Items.

Action statessemantic attributes
Interfaceroles + composable slots
<div class="popup-menu-anchor">
  <button class="button popup-menu-trigger"
    aria-haspopup="menu" aria-controls="model-menu">…</button>
  <div class="popup-menu popup-menu-anchored opens-above"
    id="model-menu" role="menu">
    <button class="action-item action-item__primary"
      role="menuitemradio" aria-checked="true">…</button>
  </div>
</div>

.opens-above sets a preference, not a rigid position. Anchored menus automatically flip to remain visible. Use menuitemradio with aria-checked for a single-choice list.
