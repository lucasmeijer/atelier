# Atelier header character — prototype verdict

Selected: **A · The tiny show-off** (strut and victory spin).

The user chose to wire A into the real Workspace header, triggered by clicking the logo. Keep the canonical mark at rest, the short excursion and return, no layout shift, and reduced-motion support. B (sneeze) and C (moonwalk) remain rejected alternatives in the exploratory HTML.

The prototype uses Atelier's real design-system stylesheet and rendered components. Its companion controller is a throwaway Stimulus explorer. Production uses a separate server renderer and focused controller, not the prototype tooling.
