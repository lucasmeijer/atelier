# Logo Easter egg verdict

Selected: Round two, 01 — The trapdoor.

The user preferred expressive eyes and a funny action: eyes appear, the logo notices a portal, silently screams, falls through, and returns from above as the ordinary mark. Retain the longer offscreen pause and instantaneous offscreen repositioning (never interpolate upward). Use a single ellipse for the bottom portal, not the prototype's double ring.

The production implementation uses server-rendered SVG, CSS keyframes and the existing small Stimulus controller. These two HTML explorers are primary-source design evidence, not production UI.
