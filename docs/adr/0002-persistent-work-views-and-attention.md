# Persist Work views and Attention requests separately from personal navigation

Atelier persists typed Work view identities, ordering, type-specific resources, and Attention requests on the server, while each browser owns its active destination, pane and drawer visibility, and scroll positions. A browser initially keeps the Work pane collapsed unless explicit navigation reveals a Work view, then restores its own navigation state on later visits. An agent-facing presentation operation requests attention for its target Work view. Agent conversations never receive Attention requests; completed Agent work contributes only to Workspace unread. This separation preserves deliberate agent control and durable presentations without introducing a generic freshness concept or forcing desktop and mobile clients to share navigation state.
