# Use view-aware mobile destinations

Atelier phone layouts show one surface at a time and use a bottom destination bar for Workspace, Agent, every open Resource Work view such as File, Browser, and Terminal, and whichever Contextual Work view is active. Contextual views such as Changes are discovered through the user-facing More destination, join the bar while active, and leave it when another destination becomes active; Work remains internal domain language rather than a mobile navigation label. Attention dots appear both on visible destinations and on entries within More, with More signaling hidden attention, while every closable destination requires a view-specific confirmation before explicit close removes its persistent state. This model preserves direct access to ongoing work without forcing every utility into permanent phone navigation.
