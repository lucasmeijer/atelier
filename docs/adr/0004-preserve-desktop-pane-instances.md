# Preserve desktop pane instances while hidden

Atelier keeps the Workspace pane, Agent pane, Work pane, and every open Work view mounted when desktop navigation hides them, so terminals, browsers, editors, scroll positions, and unsaved input survive pane and tab transitions; an explicit Work-view close is the action that removes that view. On wide desktops Workspace is a docked 275-pixel participant, while compact desktops reveal it as a dismissible overlay; Work remains a bounded 360–760-pixel resizable participant whose maximum preserves at least 420 pixels for Agent when Workspace is docked and 380 pixels when it overlays. Pane visibility, active view, and Work width restore as personal navigation state, while Work-view order and closure follow persistent Work-view state.
