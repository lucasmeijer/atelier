# Cut over directly to role-fixed presentation

Atelier will replace the process-memory arbitrary-group layout with persistent typed Work-view state and separate Agent and Work presentation interfaces in one production cutover. Production will not carry a feature flag, dual renderer, compatibility reader, or migration for the old in-memory group arrangement. Existing production tab kinds move to the new presentation interface, while Changes and the File navigator drawer remain future features. This concentrates the transition at one presentation seam and allows the generic tab/group architecture to be deleted rather than maintained alongside its replacement.
