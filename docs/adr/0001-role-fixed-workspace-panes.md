# Use role-fixed workspace panes

Atelier will replace arbitrary user-created layout groups with three role-fixed regions: a collapsible Workspace pane, a primary Agent pane, and a contextual Work pane that slides in when needed. Work views remain closable and reorderable within one resizable Work pane; their tab labels squeeze to a minimum width before scrolling horizontally. Collapsing the Work pane preserves its open views and their live state. User navigation, deep links, and agent presentation operations reveal and select their target Work views. This gives up unrestricted layout composition in exchange for a clearer interaction model that can be adapted deliberately for smaller screens.
