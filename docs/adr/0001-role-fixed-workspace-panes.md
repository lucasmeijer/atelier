# Use role-fixed workspace panes

Atelier will replace arbitrary user-created layout groups with three role-fixed regions: a collapsible Workspace pane, a primary Agent pane, and a contextual Work pane that slides in when needed. Work views remain closable and reorderable within one tab strip in the Work pane; this gives up unrestricted layout composition in exchange for a clearer interaction model that can be adapted deliberately for smaller screens.
