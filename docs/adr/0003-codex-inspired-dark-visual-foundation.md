# Use a Codex-inspired dark visual foundation

Atelier will use the accepted standalone prototype as its dark visual foundation: restrained near-black layered surfaces, compact typography and spacing, subtle borders, role-fixed Workspace, Agent, and Work regions, and controls and review treatments informed by the macOS Codex app. Codex remains a reference rather than a template to copy; Atelier keeps its own workspace, attention, File, Changes, project, and mobile interaction decisions, and ships this redesign in dark theme while preserving semantic tokens for future themes.
